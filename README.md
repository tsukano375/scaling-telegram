# 言語化トレーニング

思考を言葉にする力を、毎日少しずつ鍛えるトレーニングアプリ。

## 特徴

- **毎日更新される問題** — Claude AI が本日のテーマに合わせた5問を自動生成
- **5つのカテゴリ** — 感情 / 抽象概念 / 場面・状況 / 意見・考え / 自己内省
- **タイムチャレンジ** — 制限時間内に書き切る集中練習
- **AI フィードバック** — 明確さ・表現力・構造性の3軸でスコアリング
- **連続記録・進捗管理** — ストリーク・週次チャート・カテゴリ別平均スコア

## セットアップ

```bash
# 依存関係をインストール
npm install

# 環境変数を設定
cp .env.local.example .env.local
# .env.local に ANTHROPIC_API_KEY を入力

# 開発サーバー起動
npm run dev
```

`http://localhost:3000` にアクセスしてください。

## 技術スタック

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Anthropic Claude API** (claude-sonnet-4-6)
- **localStorage** (進捗データ保存)

## 使い方

1. 「練習」タブを開くと、今日のテーマと5つの問題が表示される
2. 問題を選んでスタートボタンを押す
3. 制限時間内に思考を言語化して提出
4. Claude が即座にフィードバックを返す
5. 毎日繰り返すことで言語化力が伸びる
